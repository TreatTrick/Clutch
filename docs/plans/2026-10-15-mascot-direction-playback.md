# Mascot Direction Playback Implementation Plan

**Goal:** 鼠标只控制龙女仆情绪视频的播放方向，播放速度始终独立于鼠标速度；悲伤仅能在弹窗右上角十六分之一区域触发。

**Architecture:** 在现有 `SupportModel` 内保留单一帧游标，以单调时钟的实际经过时间乘以原视频的 24 fps 推进。鼠标到关闭按钮的距离变化只决定正向或反向，不再映射目标帧。

**Tech Stack:** Swift、AppKit、SwiftUI、ImageIO，沿用现有 HEIC 帧资源。

## Design

- 采用用户指定的方向控制。继续使用距离映射或给距离映射增加缓动，仍然会让动画节奏受鼠标速度影响，因此不采用。
- 悲伤触发区域为弹窗最右侧 1/4 宽度与最顶部 1/4 高度的交集，即右上角 1/16。在区域内靠近关闭按钮时反向播放，远离时正向播放；直接悬停在关闭按钮上时反向播放。
- 区域外一律正向播放到开心端点，包含从 Star 移到打赏按钮的路径；区域内停下后沿最后确认的方向播到端点并保持。
- 以 3 pt 的累计距离变化过滤轻微抖动；慢速移动同样能够累计触发方向变化。
- 两个鼠标位置都在同一个关闭按钮屏幕矩形下比较，避免仅移动弹窗就触发方向变化。
- 按 60 Hz 采样鼠标和刷新，按实际时间推进 24 fps 视频；长时间主线程阻塞后最多补进 0.1 秒，避免跳过大量画面。
- 保留轻微呼吸缩放和减少动态效果设置，取消视频帧本身的正弦摆动。
- 收藏或赞助从当前情绪帧以原速播到开心端点，然后显示庆祝视频首帧；返回恢复悲伤首帧并重置鼠标方向。
- 设置窗口底栏由约 52 pt 加高到 104 pt，在咖啡按钮左侧放置 48×96 pt 的龙女仆视图，复用 `sad2Happy3.mp4` 生成的情绪帧。
- 底栏使用独立的播放器状态，但复用现有播放实现：鼠标向咖啡按钮靠近时正向变开心，远离时反向变悲伤；鼠标在按钮内保持开心，静止沿最后方向播到端点。
- 底栏通过按钮背景中的原生视图获取真实屏幕坐标，避免受窗口标题栏或窗口移动影响；窗口失去活动状态或视图消失时停止底栏播放器。

## Implementation

1. 修改 `Clutch/Mascot.swift`：替换距离映射，加入方向阈值和按经过时间推进的游标，更新状态转换，保留并更新相关注释。
2. 修改 `Clutch/SupportView.swift`：移除不再参与交互的赞助区域位置上报。
3. 修改 `README.md`：记录鼠标方向与原速播放的行为。
4. 按项目约定不新增单元测试；用户已明确自行验证和测试，停止后续验证及临时预览。
5. 修改 `Clutch/MainView.swift`：加高底栏，在咖啡按钮左侧接入动画及按钮位置追踪；复用 `MascotView` 和 `SupportModel` 的咖啡按钮交互模式。

## Verification

以下检查项留给用户自行执行。

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Clutch.xcodeproj -scheme Clutch -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath .build/dd build
git diff --check
```

用户自行核验重点：区域外始终正向播放；从 Star 移到打赏不触发悲伤；区域内靠近关闭按钮才倒播；同样一秒播放时间，快慢移动都仅推进约 24 帧；反向从当前帧连续倒播；静止后继续到端点；微小抖动不反复切换方向；进入庆祝时不回到悲伤首帧。
