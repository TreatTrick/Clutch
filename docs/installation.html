MouseSpell 安装与使用指南MouseSpell Installation & Quick Start

v1.0.1 · Universal · macOS 15+

系统要求：macOS 15 Sequoia 或更高版本，支持 Apple Silicon 和 Intel。

Requires macOS 15 Sequoia or later. Universal app for Apple Silicon and Intel.

此版本使用 Apple Developer ID 证书签名并通过 Apple 公证。macOS 会在首次打开时验证应用。

This release is signed with an Apple Developer ID certificate and notarized by Apple. macOS verifies the app when you open it.

  1. 1 · 拖动安装1 · Drag to install

    打开下载的 DMG，将安装窗口中的 MouseSpell 拖到 Applications（应用程序）快捷入口。复制完成后，从“应用程序”文件夹打开 MouseSpell；随后可以推出安装磁盘。

    Open the DMG and drag MouseSpell onto the Applications shortcut. After copying, launch MouseSpell from Applications. You can then eject the installer disk.

  2. 2 · 首次打开2 · Open MouseSpell

    从“应用程序”文件夹打开 MouseSpell。如 macOS 询问是否打开，请确认应用名称后选择“打开”。

    Open MouseSpell from Applications. If macOS asks whether to open it, verify the app name and choose Open.

  3. 3 · 开启辅助功能权限3 · Enable Accessibility

    在 MouseSpell 中点击 “打开系统设置”，前往 “隐私与安全性 → 辅助功能”，开启 MouseSpell 的权限。MouseSpell 会自动识别授权变化。

    In MouseSpell, click Open System Settings and enable MouseSpell under Privacy & Security → Accessibility. MouseSpell detects the change automatically.

  4. 4 · 添加快捷键4 · Add a shortcut

    打开 MouseSpell 主窗口，在录制区域按住一个修饰键（⌃ Control、⌥ Option、⌘ Command、⇧ Shift 或 fn），再按鼠标按键或滚动滚轮，最后选择要触发的系统动作。保存后，使用相同的“修饰键＋鼠标操作”组合即可触发。

    In MouseSpell's main window, hold a modifier key (⌃ Control, ⌥ Option, ⌘ Command, ⇧ Shift, or fn) in the recorder, press a mouse button or scroll, then choose a system action. Use the saved modifier and mouse combination to trigger it.

    切换桌面需要开启“系统设置 → 键盘 → 键盘快捷键 → 调度中心”中的“向左移动一个空间”和“向右移动一个空间”。关闭 MouseSpell 窗口后，应用仍会在菜单栏运行，可从菜单栏重新打开。

    For desktop switching, keep “Move left a space” and “Move right a space” enabled in System Settings → Keyboard → Keyboard Shortcuts → Mission Control. MouseSpell keeps running in the menu bar when you close its window; use the menu bar icon to reopen it.
