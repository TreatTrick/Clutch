# Clutch website

## Register

brand

## Platform

web

## Purpose

A minimal product website for Mac users who want to switch desktops or trigger system gestures with modifier keys and mouse buttons. The primary action downloads the existing Universal DMG; the secondary opens the public source repository.

## Approved scope

The user requested a minimal, focused website, English/Chinese/Japanese, dark/light appearance, and implementation inside D:/project/Clutch using Svelte, Vite, and pnpm, followed by deployment. Use SvelteKit static generation to deliver crawlable HTML on GitHub Pages. Preserve the existing blue app icon and actual screenshots/demo.

## Design

Neutral surfaces, a blue accent, generous space, strong typographic hierarchy, one dominant demonstration, six concise action rows, setup steps, and honest installation requirements. Keyboard navigation, visible focus, reduced motion, and responsive content are implementation requirements.
